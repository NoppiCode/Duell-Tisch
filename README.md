# Duell-Tisch 🏒⭐

Minispiele für 1 oder 2 Kinder an einem Handy. Bei zwei Spielern liegt das Handy flach zwischen den Kindern, und jedes spielt auf seiner Hälfte.

## Spiele
| Spiel | 1 Spieler | Gegeneinander | Zusammen |
|---|---|---|---|
| Noppen-Hockey | ✔ (gegen Roboter) | ✔ | – |
| Ball-Jonglage | ✔ | – | ✔ |
| Tauziehen | ✔ (gegen Roboter) | ✔ | – |
| Sternen-Schnapp | ✔ (gegen Roboter) | ✔ | ✔ |

Im 1-Spieler-Modus gibt es ⭐ Sterne. Im Shop kann man damit Schläger, Tische, Bälle, Lichteffekte, Spuren, Torjubel und Klänge kaufen. Außerdem gibt es einen täglichen Bonus.

## Auf GitHub Pages veröffentlichen
1. Neues Repository anlegen, z. B. `NoppiCode/DuellTisch`.
2. Alle Dateien aus diesem Ordner (index.html, manifest.json, sw.js, icons/) ins Hauptverzeichnis hochladen.
3. Settings → Pages → Branch `main` / Ordner `/ (root)` → Save.
4. Nach ein bis zwei Minuten ist das Spiel unter `https://noppicode.github.io/Duell-Tisch/` erreichbar.
5. Auf dem Android-Handy in Chrome öffnen → Menü ⋮ → „App installieren“ oder „Zum Startbildschirm hinzufügen“.

Nach einem Update in `sw.js` die Zahl in `duelltisch-v1` erhöhen (z. B. `v2`). Dann laden die Handys die neue Version.
